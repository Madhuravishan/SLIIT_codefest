TCP vs UDP

  • TCP: Reliable, connection-oriented, guarantees delivery. Uses 3-way handshake (SYN, SYN-ACK, ACK).
  • UDP: Fast, connectionless, no delivery guarantee. Used for DNS, streaming.

Auth & Access

  • Authentication: Proving WHO you are (e.g., passwords).
  • Authorization: WHAT you are allowed to do.
  • Least Privilege: Giving only the minimum access needed.

Web Security Big 4

SQL InjectionUnsanitized input hitting the DB. (e.g., ' OR 1=1)
XSSMalicious JS executing in the victim's browser.
CSRFAbuses browser auto-sending session cookies.
IDORChanging an ID (?user=2) to view others' data.

Cryptography Basics

Encoding (Base64)Not secure. Reversible by anyone. Ends in =.
Encryption (AES/RSA)Secure. Reversible ONLY with a key. AES=Symmetric.
Hashing (SHA256)One-way/Irreversible. Used for passwords/integrity.
