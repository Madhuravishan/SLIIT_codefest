1. CYBERSECURITY FUNDAMENTALS

The CIA Triad

Confidentiality: Preventing unauthorized access (e.g., Encryption, Passwords).
Integrity: Preventing unauthorized modification (e.g., Hashing, Digital Signatures).
Availability: Ensuring authorized access (e.g., Backups, DDoS protection).

Core Terminology

  • Vulnerability: A weakness in a system.
  • Threat: Something that could exploit a vulnerability.
  • Risk: Probability x Impact.
  • Zero-Day: An unknown vulnerability with no patch.

Authentication vs Authorization

Authentication: "Who are you?" (Passwords, Biometrics)
Authorization: "What are you allowed to do?" (Permissions, Roles)

OSI Model (Memory Trick: Please Do Not Throw Sausage Pizza Away)

  1. Physical: Cables, bits.
  2. Data Link: MAC Addresses, Switches.
  3. Network: IP Addresses, Routers, Packets.
  4. Transport: TCP/UDP, Ports, Segments.
  5. Session: Connection setup.
  6. Presentation: Formatting, Encryption (SSL/TLS).
  7. Application: HTTP, FTP, DNS. (What the user interacts with).
3. WEB SECURITY (OWASP)

HTTP Status Codes

200s (Success): 200 OK, 201 Created.
300s (Redirection): 301 Moved Permanently, 302 Found.
400s (Client Error): 400 Bad Req, 401 Unauthorized, 403 Forbidden, 404 Not Found.
500s (Server Error): 500 Internal Error, 502 Bad Gateway, 503 Service Unavailable.

Key Vulnerabilities

  • SQL Injection (SQLi): Injecting SQL commands into input. Trap: ' OR 1=1 --
  • Cross-Site Scripting (XSS): Injecting malicious JS into a webpage viewed by others. Types: Reflected, Stored, DOM.
  • Cross-Site Request Forgery (CSRF): Forcing an authenticated user to execute unwanted actions.
  • IDOR (Insecure Direct Object Reference): Changing an ID parameter to access others' data (e.g., user_id=2).
  • Directory/Path Traversal: Accessing files outside the web root. (e.g., ../../../../etc/passwd).
4. CRYPTOGRAPHY

The Most Important Rule

Encoding (Base64, Hex) is for data format compatibility. It requires NO KEY to reverse.
Encryption (AES, RSA) is for confidentiality. It REQUIRES A KEY to reverse.
Hashing (MD5, SHA-256) is for integrity. It is ONE-WAY and cannot be reversed (only cracked via brute-force/rainbow tables).

Symmetric vs Asymmetric Encryption

Symmetric: Uses ONE shared key to encrypt and decrypt. Fast. (AES, DES).
Asymmetric: Uses a PAIR of keys (Public & Private). Slow but solves key distribution. (RSA, ECC).

Recognizing Data

  • SGVsbG8gV29ybGQ= -> Ends in '=', likely Base64.
  • 48 65 6c 6c 6f -> Numbers 0-9, A-F, likely Hexadecimal.
  • Uryyb Jbeyq -> Looks shifted, likely ROT13 / Caesar Cipher.
5. LINUX COMMANDS

pwd: Print working directory.
ls -la: List all files including hidden.
cat: Read file content.
grep: Search for text within files.
find / -name "flag.txt": Search entire system for a file.
chmod: Change permissions.
chown: Change owner.
whoami: Current user.
strings file.bin: Extract printable characters from a binary (CRITICAL for CTF).

Permissions Calculator (r=4, w=2, x=1)

755 = Owner(4+2+1=7), Group(4+1=5), Others(4+1=5).
Read/Write/Execute for owner, Read/Execute for others.

6. CTF TOOLKIT
  • Nmap: Network mapper. Port scanning and service enumeration.
  • Wireshark: PCAP analysis. Network traffic sniffing.
  • Burp Suite: Web proxy. Intercept and modify HTTP requests.
  • Gobuster / Dirsearch: Directory brute-forcing.
  • John the Ripper / Hashcat: Password and hash cracking.
  • CyberChef: The "Swiss Army Knife" for encoding/decoding/crypto.
  • Ghidra: Reverse engineering / decompilation.

COMPETITION STRATEGY

How to approach the 60-minute physical MCQ.

EXAM TACTICS

  • First Pass: Answer all questions you 100% know immediately. Skip long or confusing ones.
  • Second Pass: Attack the questions that require a bit of thought or calculation (e.g., subnetting, permissions).
  • Elimination: Cross out obviously wrong answers. In multiple choice, eliminating 2 wrong answers raises your guess probability to 50%.
  • Time Management: Don't spend more than 1 minute on a single question.
